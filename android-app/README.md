# Mindbot Genius - Android App

App ini adalah wrapper Capacitor yang membuka website Mindbot Genius di:
https://mindbot-genius-ai.vercel.app

## Cara build manual
1. npm install
2. npx cap add android
3. npx cap sync
4. npx cap open android (perlu Android Studio)

## Auto-build via GitHub Actions
Push ke branch main → APK otomatis dibuild dan tersedia di tab Releases GitHub
